## Priority & Implementation Order

Ranking methodology: **risk‑reduction first** (data loss > silent failure > DX gap), then **dependency chain**, then **quick‑win value**.

| Order  | Phase                      | Group                            | Items     | Priority Rationale                                                                                                                                                                                | Risk if Deferred                                                                                         | Go / No‑Go Gate                               |
| ------ | -------------------------- | -------------------------------- | --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- | --------------------------------------------- |
| **1**  | **PATCH — Critical Fixes** | **GRP-REDIS**                    | A1 → A2   | **Data loss risk.** A1 eliminates the RMW race that violates ADR-004 and Principle 4 (Stateless Core). A2 fixes error misclassification in the same file — do together.                           | Concurrent `run()` calls with same `sessionId` silently overwrite messages.                              | A1 has SPBED plan + redis client v5 confirmed |
| **2**  | **PATCH — Critical Fixes** | **GRP-VALIDATION (A3 only)**     | A3        | **Silent rejection.** Valid tool schemas using `$ref`, `const`, etc. produce `z.never()` and fail silently — violates Principle 1 (Explicit Over Magical).                                        | Users diagnose "tool doesn't work" with no actionable error.                                             | A3 plan approved                              |

- `→` = sequential (must ship before)
- `∥` = parallel (independent, can be implemented concurrently)
- Items within a group use the same order symbol within that column
